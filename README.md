# 🧪 Proyecto de Pruebas Automatizadas con Selenium

Este repositorio contiene pruebas automatizadas utilizando **Python**, **Selenium** y **webdriver-manager**, lo que permite ejecutar los tests sin instalar drivers manualmente (ChromeDriver, GeckoDriver, etc.).

Estas pruebas están pensadas para validar formularios y flujos web básicos con la ejecución local del navegador.

---

# 📌 Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

- **Python 3.8 o superior**
- **Google Chrome** (recomendado)
- **Git**
- Permisos para ejecutar scripts en tu sistema

---

# 🚀 Instalación y configuración

Sigue los pasos para preparar el entorno de pruebas.

---

## 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/tu-usuario/tu-repo.git
cd tu-repo
```


## 2️⃣ Crear un entorno virtual (recomendado)
```
python -m venv venv
venv\Scripts\activate
```

## 3️⃣ Instalar dependencias
```
pip install -r requirements.txt
```


## ▶️ Ejecución de pruebas
```
/test/

python test/test_formulario.py

```
